# JayBlock allowlist
# Syntax: one domain per line. The domain and all names under it are exempt
# from every upstream source. Comments immediately above an entry are the
# reason. Do not allowlist a shared CDN or cloud provider just because one
# service uses it.

# YouTube ads and video share googlevideo.com / youtube.com infrastructure.
# Domain blocking cannot remove YouTube ads without breaking playback.
# Evidence: Little Snitch/Pi-hole community; PipePipe #2757; accessed 2026-09-18.
googlevideo.com
youtube.com
youtu.be
youtube-nocookie.com
ytimg.com
ggpht.com
youtubekids.com
jnn-pa.googleapis.com
youtubei.googleapis.com

# GitHub user/content CDN. githubusercontent.com is a public suffix, so this
# exempts the whole namespace rather than a single hostname.

githubassets.com

# npm public registry and CDN. Blocking breaks package installs.
